> **Status:** Pendente  
> **Jira:** —

---

## 1. User Story

Como **Product Manager**  
Preciso converter meu parágrafo de ideação em uma spec formatada estruturada  
Para que possa passar essa spec à equipe de engenharia sem redigitar manualmente

---

## 2. Contexto Técnico

Cria skill pública em `java/src/main/resources/targets/claude/skills/core/plan/x-feature-ideate/SKILL.md`:
- Frontmatter: `name: x-feature-ideate`, `model: opus` (deep-reasoning), `user-invocable: true`
- Argument: `<paragraph or text-file>`
- Phases:
  - P0: worktree-create `feature-ideation-<slug>`
  - P1: análise prosa (rules, stories preliminares)
  - P2: escrita spec (RA9 v2 minimal)
  - P3: commit + PR `→ develop`
  - P4: report com link PR + instrução invoke `x-feature-create`

---

## 3. Entrega de Valor

**Medida:** Reduzir tempo "ter ideia" → "ter spec.md" de ~30 min para <5 min  
**Impacto:** Usuários podem iterar em especificação assistida  
**Risco mitigado:** Entrada manual de spec pré-requisito foi barreira de uso

---

## 4. Contrato de Dados

Entrada: prosa livre (min 100 chars)  
Saída: `docs/specs/SPEC-<slug>-v1.md` (RA9 v2 minimal: Sistema/Escopo/Rules/Histórias/DoR-DoD)

---

## 5. Diagrama de Fluxo

```
Usuário: "Criar feature de exportação CSV..."
    ↓
x-feature-ideate (worktree feature-ideation-csv-export)
    ├─ P1: Análise prosa → rules, stories preliminares
    ├─ P2: Escrita SPEC-csv-export-v1.md
    ├─ P3: Commit + Push + PR docs/feature-csv-export → develop
    └─ P4: Report: "PR #NNN criado; revise antes de invocar x-feature-create SPEC-csv-export-v1.md"
```

---

## 6. Critérios de Aceitação

```gherkin
Funcionalidade: Ideação Assistida

  Cenario: Prosa → spec em <5 min
    Dado parágrafo "Implementar exportação CSV com filtros..."
    Quando invoco `/x-feature-ideate`
    Entao spec gerado em `docs/specs/SPEC-<slug>-v1.md`
    E PR criado em `docs/feature-<slug>` com label `docs`
    E operador pode revisar/editar antes de invocar `x-feature-create`

  Cenario: Spec válido (RA9 mínimo)
    Dado spec gerado
    Quando valido estrutura
    Entao presente: Sistema, Escopo, Regras, Histórias, DoR/DoD
    E todas as seções têm conteúdo significativo (>100 chars cada)

  Cenario: Worktree isolado
    Dado invocação de ideate
    Quando valido contexto
    Entao worktree criado em `.claude/worktrees/feature-ideation-<slug>/`
    E checkout principal não afetado
```
