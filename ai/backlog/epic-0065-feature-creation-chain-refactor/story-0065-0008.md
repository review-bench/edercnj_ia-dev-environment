## 2. Contexto Técnico

- **Source-of-truth (D-R2):** scripts moram em `java/src/main/resources/targets/claude/scripts/`; geração propaga para `.claude/scripts/`. Edição direta em `.claude/scripts/` ou `scripts/` (root) é proibida.

- **Arquivos afetados:**
  - `java/src/main/resources/targets/claude/scripts/audit-skill-visibility.sh` — grep reconhece os 3 novos `x-internal-*` da chain (`x-internal-epic-create`, `x-internal-epic-map`, `x-internal-story-create`) sob path `core/internal/plan/`
  - `java/src/main/resources/targets/claude/scripts/audit-epic-branches.sh` — adiciona regex para tipo `docs/<XXXX>-<slug>` e `docs/feature-<slug>`; valida que `epic/XXXX` existe quando `docs/<XXXX>-` é detectado
  - `java/src/main/resources/targets/claude/skills/core/git/x-git-cleanup-branches/SKILL.md` — preservação de `docs/*` enquanto PR aberto (via `gh pr list --head <branch> --state open`); cleanup só após merge ou close

- **Sub-tarefas detalhadas:**
  - **`audit-skill-visibility.sh`:** baseline existente continua válido; adicionar 3 entries permitidas em `core/internal/plan/x-internal-{epic-create,epic-map,story-create}/`. Verificar que internals fora desse path falhem com `SKILL_VISIBILITY_VIOLATION` (exit 1).
  - **`audit-epic-branches.sh`:** estender regex de branch type para incluir `^docs/[0-9]{4}-[a-z0-9-]+$` e `^docs/feature-[a-z0-9-]+$`. Para `docs/<XXXX>-`, validar que `epic/XXXX` existe em origin (idempotency).
  - **`x-git-cleanup-branches`:** adicionar grep `docs/` no preserve-list; testar que `docs/0065-csv-export` não é deletada enquanto PR existe.

- **Exit codes (Rule 26):**
  - 0 = OK
  - 1 = `SKILL_VISIBILITY_VIOLATION` ou `EPIC_BRANCH_VIOLATION` (não pinar exit numérico — usar named constant em stderr)
  - 2 = `OPERATIONAL_ERROR` (jq, gh ausentes)
  - 3 = `BASELINE_CORRUPT` (se aplicável)
