## 1. Contexto & Escopo

**Chave Jira:** —

O EPIC-0060 (Reorganização da Estrutura de Pastas v4) entregou em modo `Parcial`: o esqueleto v4 (`ai/epics/`, `ai/runs/`, `ai/releases/`, `docs/adr/`, `docs/specs/`, `governance/baselines/`), o helper `PathResolver` (com probe v3↔v4) e o script `scripts/migrate-layout.sh` foram mergeados, mas a **migração física dos arquivos** e a **atualização de referências cruzadas** foram adiadas por força da RULE-010 (atomic CI workflow updates) — mover arquivos sem reescrever todas as referências no mesmo PR quebraria o CI. Este épico finaliza o trabalho deferido: move ADRs (21 arquivos), specs (11 arquivos) e baselines (7 arquivos) para o layout v4, atualiza 14 SKILLs que ainda referenciam `plans/epic-XXXX` em strings literais, atualiza Rules 05/13/24/25/26/27/45 e regenera as 11 fixtures de golden files. Após este épico, somente epics legados (0001-0060, `flowVersion ≤ 2`) permanecem em `plans/` em modo read-only conforme RULE-001 do EPIC-0060.

A migração é dividida em **8 histórias em ordem topológica**: refatoração dos audit scripts para parametrização de path (pré-requisito), movimentação dos baselines, movimentação dos ADRs (com atualização das refs em `CLAUDE.md`, `Conventions.md`, `README.md`), movimentação dos specs, atualização dos Java assemblers + `FileCategorizer`, conversão de 14 SKILLs para `PathResolver`, atualização das Rules afetadas e cleanup final (remoção de symlinks temporários e diretórios v3 vazios). Cada história termina com CI verde, permitindo merge incremental para `epic/0062` via auto-merge e gate manual final para `develop`. O freeze de `plans/` (hook `forbid-writes-to-legacy-plans`) e o bump MAJOR ficam para os EPICs 0063 e 0064 respectivamente, gated por janela de coexistência de 2 sprints.

## 3. Contratos & Endpoints

Épico de migração estrutural. Nenhum endpoint REST/gRPC exposto. Artefatos:

- **Movimentação física:** `git mv` aplicado em 39 arquivos (21 ADRs + 11 specs + 7 baselines).
- **Reescrita textual:** ~50 arquivos (CLAUDE.md, Conventions.md, README.md, 7 rules, 14 SKILLs, 5 Java assemblers + `FileCategorizer`, 6 audit scripts).
- **Regeneração:** 11 perfis de golden fixtures regenerados via `mvn test -Dtest=GoldenFileRegenerator -DupdateGolden=true`.
- **Symlinks temporários:** `audits/ → governance/baselines/` durante PR de movimentação dos baselines, removido na story de cleanup.

### 3.1 Contrato de `BASELINE_DIR` (RULE-005)

Audit scripts passam a aceitar variável de ambiente `BASELINE_DIR` com default `governance/baselines`:

```bash
BASELINE_DIR="${BASELINE_DIR:-governance/baselines}"
```

Scripts afetados: `audit-baseline-immutability.sh`, `audit-execution-integrity.sh`, `audit-pr-evidence.sh`, `audit-phase-gates.sh`, `audit-task-hierarchy.sh`, `setup-branch-protection.sh`.

### 3.2 Exit Codes Preservados

Todos os scripts mantêm exit codes existentes do EPIC-0058 (Rule 26). Nenhum código novo.

## 9. Riscos & Mitigações

| Risco | Probabilidade | Impacto | Mitigação |
