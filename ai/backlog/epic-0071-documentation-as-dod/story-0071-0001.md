## 2. Entrega de Valor

- **Valor primário:** fundação contratual (capability + rule + ADR + schema YAML) bloqueia drift do gate doc-as-dod antes de existirem skills consumidoras.
- **Valor secundário:** `DocumentationConfig.java` parseável permite stories 0002/0003/0005 consumirem o bloco YAML de forma type-safe.
- **Métrica:** capability YAML + rule .md + ADR .md publicados em commit único; `DocumentationConfig.java` cobre 100% do schema YAML novo; `mvn verify` verde. **Quantitativa:** `DocumentationConfig.parseFrom()` p95 latency < 500ms para YAML com 50+ targets (medido via JMH microbenchmark ou JUnit `assertTimeout`). Audits dedicados `audit-capability-coverage.sh` / `audit-frontmatter-schema.sh` referenciados na Rule 28 são planejados em EPIC-0064 Phase 2 e **não bloqueiam** esta story; quando entregues, AC desta story passa a citá-los explicitamente.

## 6. Decision Rationale

**Decisão:** Bloco `documentation` no YAML principal do `ProjectConfig` (não arquivo dedicado). **Motivo:** single source of truth — operadores configuram tudo no mesmo YAML. **Alternativa descartada:** arquivo separado `documentation.yaml` (gera fragmentação + dual-read). **Consequência:** YAML do projeto cresce; aceitável dado que `documentation.targets` é declarativo curto.

## 7. Refinement Notes (consolidadas)

- **Defaults derivados quando bloco YAML ausente:** README sempre; OpenAPI quando `interfaces[].spec=openapi` declarado; AsyncAPI quando `interfaces[].broker` não vazio; gRPC proto quando `interfaces[].spec=proto3`; ADR sempre; skill-docs sempre se `.claude/skills/` existir; system-architecture sempre se `docs/architecture/system.md` existir (EPIC-0070).
- **Interface com EPIC-0070 (system.md target):** capability declara dependência soft em `governance.value-driven-templates`; ausência causa modo degradado (skill `x-doc-validate` pula validação de `system.md`).
- **`freshness-window-hours` semântica:** 0 = imediato (PR é blocked se diff de código sem diff de doc); >0 = tolerância em horas (raro, usado para releases com grace period). Default 0.
- **Integração com Rule 24 (artefato evidência):** `_TEMPLATE-DOC-VALIDATE-REPORT.md` (entregue em story-0071-0002) será o artefato evidência do `x-doc-validate` registrado em Rule 24 §Mandatory Evidence Artifacts.
