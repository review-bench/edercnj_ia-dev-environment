# História: Criar `_TEMPLATE-ARCHITECTURE-SYSTEM.md` (auto-fill via YAML, 11 seções)

**ID:** story-0070-0004
**Status:** Pendente
**Refinement Verdict:** TBD

> 🟡 **REFINEMENT REQUIRED**

## 1. Visão
Como **arquiteto / novo dev**, quero `docs/architecture/system.md` vivo descrevendo a arquitetura técnica completa do sistema, alimentado parcialmente pelo YAML do projeto (stack, persistência, comunicação, observabilidade) e seções narrativas para decisões manuais.

## 2. Entrega de Valor
- Arquitetura técnica vive em **um arquivo só**, navegável.
- Métrica: novo dev consegue mapear arquitetura em 30min lendo só o `system.md`.

## 3. Acceptance Criteria
```gherkin

  DADO YAML do projeto declara java 21 + Spring 3.x + postgres 17 + kafka
  QUANDO ia-dev-env generate roda
  ENTÃO docs/architecture/system.md é criado
  E "Stack Resolvida" contém java 21 + spring-boot 3.x
  E "Persistência" contém postgresql 17 + flyway
  E "Comunicação" contém REST + gRPC + Kafka events
```

## 6. Decision Rationale
**Decisão:** template + auto-fill parcial. **Motivo:** YAML traz "o quê", operador escreve "como/por quê". **Alternativa descartada:** 100% auto-fill. **Consequência:** placeholders bem documentados no template.
