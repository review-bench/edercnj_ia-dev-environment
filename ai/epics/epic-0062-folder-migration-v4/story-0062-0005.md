## 1. Contexto & Escopo

Como **mantenedor do gerador `ia-dev-env`**, eu quero atualizar os 5 assemblers Java + `FileCategorizer` para emitir nos paths v4 (`docs/adr/`, `docs/specs/`, `governance/baselines/`, `ai/releases/`) e regenerar os 11 perfis de golden fixtures, eliminando os symlinks transitórios criados nas stories 0062-0002, 0062-0003 e 0062-0004.

Esta é a história de **convergência**: bloqueada pelas três anteriores (audits movidos, ADRs movidos, specs movidos) e produz um estado final limpo onde Java emite no novo layout sem depender de symlinks. Implica regen das 11 fixtures (`java/src/test/resources/golden/{9 perfis Java + parallelism-heuristics + x-parallel-eval}/`), o que gera diff massivo no PR mas é necessário para que os smoke tests reflitam o novo layout.
