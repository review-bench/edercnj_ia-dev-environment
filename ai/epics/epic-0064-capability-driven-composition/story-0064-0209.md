## 6. Decision Rationale

**Decisão:** Aceitar AI fallback em 30-40% das skills security/CI; revisão manual obrigatória por categoria.
**Motivo:** Heurística por path/keyword cobre ~70% dos casos. Skills security têm jargão específico (e.g., "OWASP", "SLSA", "EPSS") que AI fallback infere mas nem sempre acerta. Manual review é o gate de qualidade.
**Alternativa descartada:** Forçar 100% heurístico (sem AI fallback). Rejeitada porque requer engenharia upfront de tabela keyword→capability extensa que não vale para ~25 skills.
**Consequência:** PR de revisão recomendado por subdiretório (`release/` separadamente de `ops/`); revisor valida que `requires-capabilities` AI-inferido faz sentido.

## 7. Implementation Notes

Esta é a story mais "longa-cauda" — várias skills com perfis distintos. AI fallback de `/x-frontmatter-migrate` provavelmente acionado para 30-40% das skills security/CI (heurística não cobre todas). Revisão manual recomendada.
