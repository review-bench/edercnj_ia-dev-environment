## 1. Contexto

Implementa `CycleDetector` (`dev.iadev.application.capability`) usando o algoritmo de Tarjan para SCC (Strongly Connected Components). Detecta ciclos no grafo de prerequisites (`requires` chains) e devolve a sequência exata do ciclo via `CapabilityError.CycleDetected`.

Tarjan SCC é O(V+E), determinístico, e lida com grafos esparsos (~80 capabilities, ~3 edges médios). Substitui DFS naïve com complexidade O(V²) que era proposta inicialmente.

## 2. Acceptance Criteria

```gherkin
Scenario: Single node sem arestas (degenerate)
  Given graph com 1 node e 0 edges
  When CycleDetector.detect(graph)
  Then returns Optional.empty()
  And não emite warnings

Scenario: Grafo acíclico passa (happy)
  Given graph A→B→C (sem ciclos)
  When CycleDetector.detect(graph)
  Then returns Optional.empty()

Scenario: Ciclo direto detectado (error path)
  Given graph A→B, B→A
  When CycleDetector.detect(graph)
  Then returns CycleDetected with path [A, B, A]

Scenario: Ciclo indireto detectado (error path)
  Given graph A→B→C→A
  When CycleDetector.detect(graph)
  Then returns CycleDetected with path [A, B, C, A]
  And error message lists 3 nodes em cycle order

Scenario: Múltiplos SCCs reportados deterministicamente (boundary)
  Given graph com 2 ciclos disjuntos: [A,B] e [X,Y]
  When CycleDetector.detect(graph) chamado 3x
  Then todas as 3 invocações retornam CycleDetected do mesmo SCC (alphabetically first by min-id)
  And SCC remanescente flagrada via ResolutionWarning
```

## 6. Decision Rationale

**Decisão:** Tarjan SCC iterativo (não-recursivo).
**Motivo:** RULE-004 (determinismo) + complexidade O(V+E) — versão recursiva sofreria stack overflow em grafos profundos hipotéticos (catálogo pode crescer); iterativo é robusto.
**Alternativa descartada:** DFS naïve com cycle stack. Rejeitada por ser O(V²) no pior caso, e por dificultar reportar o ciclo exato (apenas detecta presença).
**Consequência:** Implementação ~80 LOC em Java; primeiro SCC detectado é o reportado (early termination).

## 7. Implementation Notes

Algoritmo padrão de Tarjan: stack auxiliar, `lowlink` e `index` por nó. Iterativo (não recursivo) para evitar stack overflow em grafos profundos. `CapabilityGraph.dependentsOf(id)` é a função de adjacência.

Detecção precoce: aborta o algoritmo no primeiro SCC com size ≥ 2 — primeiro ciclo é suficiente para erro estruturado.
