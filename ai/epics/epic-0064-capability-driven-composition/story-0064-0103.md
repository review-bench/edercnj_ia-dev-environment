## 1. Contexto

Implementa `CycleDetector` (`dev.iadev.application.capability`) usando o algoritmo de Tarjan para SCC (Strongly Connected Components). Detecta ciclos no grafo de prerequisites (`requires` chains) e devolve a sequência exata do ciclo via `CapabilityError.CycleDetected`.

Tarjan SCC é O(V+E), determinístico, e lida com grafos esparsos (~80 capabilities, ~3 edges médios). Substitui DFS naïve com complexidade O(V²) que era proposta inicialmente.

## 2. Acceptance Criteria

```gherkin
Scenario: Grafo acíclico passa
  Given graph A→B→C (sem ciclos)
  When CycleDetector.detect(graph)
  Then returns Optional.empty()

Scenario: Ciclo direto detectado
  Given graph A→B, B→A
  When CycleDetector.detect(graph)
  Then returns CycleDetected with path [A, B, A]

Scenario: Ciclo indireto detectado
  Given graph A→B→C→A
  When CycleDetector.detect(graph)
  Then returns CycleDetected with path [A, B, C, A]
  And error message lists 3 nodes in cycle order

Scenario: Múltiplos SCCs reportados (degenerate)
  Given graph com 2 ciclos disjuntos
  When CycleDetector.detect(graph)
  Then returns CycleDetected for first SCC encountered (deterministic)
  And remaining cycles flagged via ResolutionWarning
```

## 4. DoD

- `CycleDetector.detect(CapabilityGraph)` implementado com Tarjan SCC.
- Complexidade O(V+E) verificada por test parametrizado (1K, 10K nodes).
- Ciclo direto + indireto detectados corretamente.
- Path do ciclo retornado em ordem topológica iniciando pelo menor ID (determinismo).
- Cobertura ≥ 95%/90%.

## 5. Implementation Notes

Algoritmo padrão de Tarjan: stack auxiliar, `lowlink` e `index` por nó. Iterativo (não recursivo) para evitar stack overflow em grafos profundos. `CapabilityGraph.dependentsOf(id)` é a função de adjacência.

Detecção precoce: aborta o algoritmo no primeiro SCC com size ≥ 2 — primeiro ciclo é suficiente para erro estruturado.
