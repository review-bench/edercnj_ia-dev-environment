## 1. Contexto

Adiciona flag `--dry-run` ao comando `generate` (CLI Picocli em `dev.iadev.adapter.inbound.cli`). Quando ativa:

- Composer roda completo: load profile → resolve → plan → render fragments → render Pebble.
- **Não escreve em disco** (OutputPruner skip).
- Output: relatório estruturado em stdout (text default; JSON com `--output-format json`).

Útil para diagnose ("o que entra/sai do meu output?") e para o pipeline de gates pre-merge (story-0064-0706 — baseline grandfathered).

## 2. Acceptance Criteria

```gherkin
Scenario: Dry-run não cria output dir
  Given output dir não existe
  When generate --config x.yaml --dry-run
  Then output dir continua não existindo
  And stdout mostra plan

Scenario: Plan listado em texto humano
  Given valid config
  When generate --dry-run
  Then stdout contém:
    - "Included artifacts: N"
    - "Excluded artifacts: M"
    - "Regenerated: K"

Scenario: --output-format json produz JSON parseável
  Given valid config
  When generate --dry-run --output-format json
  Then stdout é JSON válido
  And contém keys: included, excluded, regenerated, warnings

Scenario: Errors propagados mesmo em dry-run
  Given config com mutex conflict
  When generate --dry-run
  Then exit code = 1
  And stderr contém MutexConflict message
```
