## 1. Contexto

Audit script crítico para Rule 04 enforcement. Para cada perfil canônico:

1. Roda `generate --config x` 3 vezes consecutivas em diretórios temporários distintos.
2. Compara SHA-256 de cada arquivo gerado entre as 3 invocações.
3. Falha se houver qualquer divergência (Rule 04 violada).

Detecção dinâmica de drift de determinismo — complementa property test (story-0064-0506) que cobre via fuzzing.

## 5. Implementation Notes

Bash. Cria 3 tmpdirs por perfil, invoca generate em cada, walks os diretórios via find + sort, compute SHA-256 de cada arquivo via `shasum -a 256`, compara via diff.

Em caso de drift: report mostra primeiro arquivo divergente + diff dos primeiros 10 bytes diferentes (hint de causa-raiz).
