## 6. Decision Rationale

**Decisão:** Templates declaram `composition.skip-pebble: true` no frontmatter; CompositionEngine pula Pebble para esses arquivos.
**Motivo:** RULE-005 (three-level templating) — Composer roda antes de Pebble; LLM placeholders (`{{UPPER_SNAKE}}`) ficam para runtime. Se Pebble processar um template por engano, `{{EPIC_ID}}` vira string vazia ou erro. Skip-pebble flag previne.
**Alternativa descartada:** Convenção implícita por path (e.g., `_TEMPLATE-*` skip-pebble por nome). Rejeitada porque mistura naming convention com behavior — explicit é melhor (Zen of Python aplicado).
**Consequência:** `CompositionEngine` (story-0064-0303) checa `composition.skip-pebble` no frontmatter antes de invocar Pebble; render-as-is se true.

## 7. Implementation Notes

Pebble + Composer rodam em build-time; LLM placeholders só em runtime. Esta separação é parte do contrato (Rule 28 / RULE-005). `PebbleSafeRenderer.preflight()` falha se template foi processado por engano — esta story garante que o frontmatter sinaliza `skip-pebble`.
