## 1. Contexto

Após Phase 3 ter substituído todos os assemblers legacy pelo `CapabilityAwareComposer`, esta story **deleta fisicamente** os arquivos legacy:

- `SkillsAssembler.java`, `KnowledgeAssembler.java`, `AgentsAssembler.java`, `RulesAssembler.java`, `HooksAssembler.java`, `TemplatesAssembler.java`.
- 8 gates legacy em `application/assembler/gates/`.
- `SkillsSelection.java`, `KnowledgePackSelection.java`, `ConditionEvaluator.java`, `ChecklistInjector.java`.
- Testes correspondentes.

Total estimado: ~25-30 classes Java + ~30 testes deletados (≥3K LOC removidos).

Sem retrocompatibilidade (Rule 28 RULE-006). CHANGELOG marca como `[Breaking]`.
