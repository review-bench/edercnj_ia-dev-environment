## 1. Contexto

Implementa generators jqwik para os tipos de domínio do EPIC-0064: `CapabilityIdGenerator`, `CapabilityDefinitionGenerator`, `ProfileGenerator`, `CapabilityCatalogGenerator`. São pre-condition para a story-0064-0111 (property suite com 10K casos).

jqwik shrinking encolhe contra-exemplos automaticamente para o caso mínimo — facilita debug. Generators respeitam invariantes do domínio (IDs canônicos, requires apontando a IDs reais do catálogo gerado).

## 2. Acceptance Criteria

```gherkin
Scenario: CapabilityIdGenerator produz IDs canônicos
  When generator.tuples() generates 1000 CapabilityIds
  Then 100% match regex "^[a-z]+\\.[a-z]+\\.[a-z]+$"
  And no duplicates within a run
  And shrink target is "a.a.a"

Scenario: CapabilityCatalogGenerator produz catálogos consistentes
  When generator.catalogs() generates 100 catalogs of size 20
  Then 100% têm requires apontando a IDs do mesmo catálogo
  And nenhum tem ciclos (gerador filtra)
  And mutex symmetry holds

Scenario: ProfileGenerator produz profiles válidos contra catálogo
  Given a generated catalog
  When generator.profiles(catalog) produz 100 profiles
  Then todos ativam apenas IDs que existem no catálogo
  And nenhum ativa pair com excludes simétrico
```

## 5. Implementation Notes

jqwik 1.8+. `Arbitrary<T>` com filtros para garantir invariantes. Use `frequency()` para distribuição realista (e.g., 80% catálogos pequenos, 20% grandes).

`@Provide` permite que generators sejam injetados em property tests sem boilerplate. Dependência adicionada em `pom.xml` neste mesmo PR.
