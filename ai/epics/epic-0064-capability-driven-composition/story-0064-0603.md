## 6. Decision Rationale

**Decisão:** Bash wrapper sobre `FrontmatterValidatorCli` (Java) em vez de reimplementação Bash do schema validator.
**Motivo:** Schema validation completa requer JSON Schema parser (additionalProperties, pattern, conditional schema). Reimplementar em Bash seria ~500+ linhas e propenso a divergência do spec. Java CLI já existente é reuso natural.
**Alternativa descartada:** Reimplementar com Bash + jq. Rejeitada por (a) jq não suporta full JSON Schema, (b) divergência subtle no parsing produz false negatives.
**Consequência:** Audit-frontmatter-schema requer Java code base buildable (diferente de audit-capability-graph que é independente). Aceito porque FrontmatterValidator é central + estável.

## 7. Implementation Notes

Bash → invoke `java -cp target/classes FrontmatterValidatorCli --root targets/claude/ --json`. Parse exit code + JSON output. Reusa toda lógica do CLI Java.
