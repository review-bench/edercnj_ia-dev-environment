- Path atual.
- Conteúdo identificado como stack-specific (e.g., menção a "Spring Boot", "Quarkus", "@QuarkusTest", "@SpringBootTest").

## 6. Decision Rationale

**Decisão:** Bash + grep como ferramenta de inventário (vs Java tool dedicado).
**Motivo:** Inventário é one-shot — sem necessidade de unit testing, classes, etc. Bash + grep é direto, debugável, e produz output incrementalmente. Inventário não é hot path.
**Alternativa descartada:** Implementar `InventoryGenerator.java` como classe Java testada. Rejeitada por overhead — story é S size, código Java seria maior que conteúdo gerado.
**Consequência:** Script `scripts/dev/stack-inventory.sh` (ou one-liner em SKILL.md) produz CSV+MD; revisado manualmente; descartado pós-Phase 4.

## 7. Implementation Notes

Pode ser script Bash + grep (não precisa Java). Lista de keywords: Spring, SpringBootTest, Quarkus, QuarkusTest, Picocli, @Command (Picocli), Helidon, Micronaut, MicronautTest, JaxRS, R2DBC, etc.
