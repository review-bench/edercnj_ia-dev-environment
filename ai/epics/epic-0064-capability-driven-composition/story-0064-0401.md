## 1. Contexto

Audit informacional: catalogar todo conteúdo em `targets/claude/` que é stack-specific mas hoje vive em paths universais. Output é uma planilha (`.csv` ou markdown table) listando, por arquivo:

- Path atual.
- Conteúdo identificado como stack-specific (e.g., menção a "Spring Boot", "Quarkus", "@QuarkusTest", "@SpringBootTest").
- Stack target (spring/quarkus/picocli/helidon/micronaut/universal).
- Recomendação de migração (mover para subdir, ou extrair fragment).

Insumo crítico para stories 0402-0409 (split físico).

## 2. Acceptance Criteria

```gherkin
Scenario: Inventário lista 100% dos arquivos com conteúdo stack-specific
  Given catalog atual em targets/claude/knowledge/stack-patterns/
  When inventory tool runs
  Then output planilha contém ≥ todas as menções a "Spring", "Quarkus", "Picocli", "Helidon", "Micronaut"

Scenario: Recomendação por arquivo presente
  Given inventário completo
  When inspect each row
  Then cada row tem coluna "recommendation" preenchida (move|fragment|keep-universal)

Scenario: Output em CSV + Markdown
  Given inventory tool
  When invoked
  Then produz dois arquivos: stack-inventory.csv + stack-inventory.md
```
