## 6. Decision Rationale

**Decisão:** Reusar convenções do `ia-dev-env` próprio code base como template para skill content (self-applicable).
**Motivo:** `ia-dev-env` é Picocli application — codebase oferece exemplos battle-tested de @Command, @Option, exit codes (Rule 26 §Standardized). Reuso reduz inconsistência entre skill output e código real.
**Alternativa descartada:** Inventar convenções genéricas Picocli. Rejeitada porque (a) duplica esforço de design já feito, (b) conventions divergem de exemplos reais que devs vêem no próprio código.
**Consequência:** Skill links ou cita arquivos específicos do `ia-dev-env` codebase como reference (e.g., `dev.iadev.cli.GenerateCommand`).

## 7. Implementation Notes

`ia-dev-env` é própriamente uma aplicação Picocli — o conteúdo desta skill é também self-applicable. Reusa convenções do code base.

Lifecycle Callable<Integer>: 0=success, 1=error, 2=usage error. Consistente com Rule 26 §Standardized Exit Codes.
