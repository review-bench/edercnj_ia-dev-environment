## 6. Decision Rationale

**Decisão:** Batch invocation `/x-frontmatter-migrate targets/claude/skills/core/plan/` (vs. arquivo-por-arquivo).
**Motivo:** Path glob no skill processa todos em uma transação. Reduce overhead de invocação. Diff resultante é único PR review unit.
**Alternativa descartada:** Migração arquivo-por-arquivo com PR per skill. Rejeitada por (a) ruído de PRs múltiplos, (b) padrão de Phase 2 é batch (não incremental — RULE-008).
**Consequência:** Diff PR esperado: ~12 SKILL.md tocados, +~5 linhas por arquivo (frontmatter additions).

## 7. Implementation Notes
