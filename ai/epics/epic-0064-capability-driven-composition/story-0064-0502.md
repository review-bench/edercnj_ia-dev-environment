## 1. Contexto

`CLAUDE.md` (root) é o arquivo de instruções carregado em toda conversa. Hoje é universal — mesmo conteúdo para qualquer projeto. Esta story refatora para suportar fragments capability-driven:

- Conteúdo universal preservado em `shared/templates/CLAUDE.md` (parent).
- Fragments por capability: `fragments/database.md` (regras data), `fragments/messaging.md`, `fragments/security-pci.md`, `fragments/microservices.md`, etc.
- Parent declara `fragment-slots: [{slot: domain-specific}]`.

Resultado: `CLAUDE.md` gerado para Java CLI sem DB é mais curto e focado; projeto Spring + Postgres + PCI tem instruções específicas de DB e PCI.
