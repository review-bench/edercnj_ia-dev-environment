## 1. Contexto

Cria skill `/x-spring-controller` (`targets/claude/skills/core/dev/x-spring-controller/`) com `requires-capabilities: [web.spring.boot]`. Geração de Controller REST Spring com `@RestController`, `@RequestMapping`, validação `@Valid`, ResponseEntity.

Hoje, conteúdo Spring vem misturado em `x-doc-generate` ou KPs universais. Esta story extrai para skill dedicada — output projeto Spring ganha skill específica; projeto Quarkus/CLI não.

```gherkin
  And visibility: public

Scenario: Output Spring contém skill
  Given profile spring-rest-postgres
  When generate
  Then .claude/skills/x-spring-controller/SKILL.md existe

Scenario: Output Quarkus NÃO contém skill
  Given profile quarkus
  When generate
  Then .claude/skills/x-spring-controller/ não existe

Scenario: Skill conteúdo idiomático Spring
  Given SKILL.md
  When inspect body
  Then template usa @RestController, @RequestMapping, ResponseEntity
  And não menciona @Path (Quarkus) ou @Command (Picocli)
```
