## 1. Contexto

Cria skill `/x-frontmatter-migrate` que migra um arquivo (ou diretório) de frontmatter v2 para v3.0. Pipeline híbrido:

1. **Heurística por path:** infere `requires-capabilities` a partir do diretório (`java/src/main/resources/targets/claude/skills/core/dev/x-spring-controller/SKILL.md` → `requires: [web.spring.boot]`).
2. **Heurística por keyword:** scan no body por keywords (`Postgres`, `JPA`, `OAuth2`) → adiciona capabilities.
3. **AI fallback:** quando heurística não cobre, invoca subagente que lê o body e propõe `requires-capabilities`.
4. **Output:** escreve frontmatter v3.0 + commit via `x-planning-commit`.

Stories 0203-0214 consomem esta skill em batch para migrar 182 artefatos.

## 6. Decision Rationale

**Decisão:** Pipeline 4-stage (path → keyword → AI → write) com inferência conservadora.
**Motivo:** Path é o sinal mais confiável (estrutura imposta). Keyword é heurística baseada em conteúdo. AI é fallback caro (subagente Sonnet/Opus) só quando os 2 anteriores não cobrem. Conservadorismo evita false positives que poluam catálogo.
**Alternativa descartada:** AI direto para tudo (sem path/keyword first). Rejeitada por (a) custo desnecessário em casos óbvios (path = stack), (b) AI pode propor capabilities inexistentes (false positive).
**Consequência:** Stages 0203-0214 esperam que ~70% dos artefatos sejam cobertos por path/keyword; ~30% acionem AI fallback. Estimativa será revisitada após smoke test com primeiros 10-20 arquivos.

## 7. Implementation Notes

Skill é o orquestrador; lógica pesada delegada a subagente (heurística + AI). Heurística é tabela `Map<String, List<CapabilityId>>` indexada por path prefix + keyword stem.

Subagente recebe contexto: file path + body completo + catálogo de capabilities. Prompt instrui inferência conservadora (preferir false negative a false positive — migrações 0203-0214 vão revisar).
