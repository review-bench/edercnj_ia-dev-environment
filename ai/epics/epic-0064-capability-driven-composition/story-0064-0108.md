# Story: 0064-0108 — Erros tipados (`CapabilityError` sealed)

**Epic:** EPIC-0064

**Predecessores:** story-0064-0107 (resolver)

## 1. Contexto

Materializa `CapabilityError` como sealed interface (Java 21) em `dev.iadev.domain.capability`, com 5 implementações: `MissingPrerequisite`, `MutexConflict`, `UnknownCapability`, `CycleDetected`, `AmbiguousProfile`. Cada subtype carrega contexto estruturado (qual capability/profile, lista de IDs envolvidos, dica de remediação).

Usado pelos validators e pelo CLI `validate` (story de Phase 3) para produzir mensagens de erro acionáveis. Sealed interface permite exhaustive switch (Java 21) — adicionar novo erro força recompilação de todos os consumidores.

## 2. Acceptance Criteria

```gherkin
Scenario: MissingPrerequisite carrega referência completa
  Given resolver detecta web.spring.boot requires web.unknown ausente
  When MissingPrerequisite is thrown
  Then error.referredId() == "web.unknown"
  And error.referrerId() == "web.spring.boot"
  And error.remediationHint() suggests adding web.unknown.yaml

Scenario: CycleDetected lista path completo
  Given graph A→B→C→A
  When CycleDetected is thrown
  Then error.cyclePath() == [A, B, C, A]

Scenario: Switch exhaustive sobre CapabilityError
  Given Java 21 switch on CapabilityError
  When developer omits a case
  Then compiler error (sealed exhaustiveness)

Scenario: Erro serializa para JSON estruturado
  Given any CapabilityError instance
  When serialized via Jackson
  Then JSON contém type, message, context (specific to subtype)
```

## 4. DoD

- Sealed interface + 5 records implementando.
- Cada subtype com contexto estruturado (não apenas string).
- Serialização JSON canônica (Jackson) coerente.
- Switch exhaustivo testado.
- Cobertura ≥ 95%/90%.

## 5. Implementation Notes

Records imutáveis. `CapabilityError extends RuntimeException` para fluir naturalmente — mas a API pública do resolver retorna via `Result<ResolvedCapabilitySet, CapabilityError>` (não throw direto).

Métodos `remediationHint()` retornam strings construídas estaticamente — são parte do contrato (testes verificam exatamente o texto).
