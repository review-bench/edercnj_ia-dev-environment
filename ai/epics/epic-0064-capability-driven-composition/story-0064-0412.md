## 1. Contexto

Smoke test E2E que valida o framework split:

1. Spring profile não contém Quarkus/Picocli/Helidon/Micronaut artefacts.
2. Quarkus profile não contém Spring/Picocli/Helidon/Micronaut.
3. Picocli profile não contém Spring/Quarkus/Helidon/Micronaut.
4. Helidon profile não contém Spring/Quarkus/Picocli/Micronaut.
5. Micronaut profile não contém Spring/Quarkus/Picocli/Helidon.

Verifica disjunção total entre os 5 frameworks. Detecta vazamento de conteúdo cross-framework.

```gherkin
Scenario: Spring + Quarkus mutualmente disjuntos no output
  Given golden/spring-rest-postgres + golden/quarkus
  When test runs

  And vice-versa

Scenario: 5 frameworks disjuntos
  Given goldens dos 5 perfis
  When test runs

  And todos os pairs são disjuntos (0 overlap)

Scenario: Test detecta vazamento simulado

  When test runs
  Then test fail
  And error mostra exato file path

Scenario: Smoke roda em < 20s
  Given 5 perfis × pairwise comparison
  When test runs end-to-end
  Then wall clock < 20s
```
