## 1. Contexto

Smoke test E2E que valida o pipeline completo (resolver → composer → pruner → engine → Pebble) contra 9 perfis golden. Para cada perfil:

1. Carrega setup-config.yaml.
2. Roda generate.
3. Compara output gerado contra `src/test/resources/golden/<profile>/` byte por byte.
4. Falha se ≥1 byte diferente.

Roda em CI a cada PR. Detecta regressão imediata em qualquer ramo do composer.

## 2. Acceptance Criteria

```gherkin
Scenario: Smoke verde para todos os 9 perfis
  Given setup-configs/ com 9 perfis
  When Epic0064ComposerIntegrationSmokeTest runs
  Then 9 goldens igualam ao output gerado bytewise
  And test exit code = 0

Scenario: Smoke vermelho quando golden desalinha
  Given golden modificado manualmente (1 byte alterado)
  When Epic0064ComposerIntegrationSmokeTest runs
  Then test fail
  And error mostra diff (file path + bytes diferentes)

Scenario: Smoke roda em < 30s
  Given 9 perfis
  When test executes end-to-end
  Then wall clock < 30s (target — ajustável conforme infra)

Scenario: Smoke detecta arquivo extra/missing
  Given golden tem arquivo X que output não tem (ou vice-versa)
  When test runs
  Then test fail
  And error lista o arquivo faltante/extra
```

## 5. Implementation Notes

JUnit 5 `@ParameterizedTest` com `@MethodSource` listando os 9 perfis. Para cada: gera output em tmp dir, walks both trees, compara size + SHA por arquivo, reporta primeiro mismatch.

Para velocidade: paralelizar com `@Execution(CONCURRENT)`. 9 perfis em 4 threads ≈ 3 batches.
