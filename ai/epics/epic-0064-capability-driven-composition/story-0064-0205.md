## 6. Decision Rationale

**Decisão:** `x-test-e2e` requires `testing.e2e`; demais test/* são universais.
**Motivo:** E2E exige infra adicional (containers, real DB, network) que não está sempre presente. Projeto java-cli sem DB pode rodar TDD/unit tests mas não E2E. Diferenciação permite pruning preciso.
**Alternativa descartada:** Todas as test/* universais. Rejeitada porque inflaria output do projeto java-cli com skill que não pode usar.
**Consequência:** Profile sem `testing.e2e` ativo não recebe `.claude/skills/x-test-e2e/`. Profile com (e.g., spring-rest-postgres) recebe.
