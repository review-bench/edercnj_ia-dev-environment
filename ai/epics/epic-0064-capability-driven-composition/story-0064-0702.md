## 6. Decision Rationale

**Decisão:** Bloco conciso (~30-40 linhas) com cross-refs externos para detalhes; não inline conteúdo extensivo.
**Motivo:** CLAUDE.md já é ~600+ linhas — adicionar 100+ linhas de detalhes infla o context window de toda conversa. Cross-refs para Rule 28 + ADR-0016 + SPEC permitem deep-dive on-demand sem inflate o sempre-ativo.
**Alternativa descartada:** Inline detailed walkthrough (e.g., 200+ linhas com exemplos). Rejeitada porque (a) repete conteúdo de Rule 28 / ADR / SPEC, (b) inflate context cost.
**Consequência:** Manutenção: ao mudar Rule 28 ou ADR-0016, CLAUDE.md cross-refs continuam válidos sem update (referências por nome, não conteúdo).
