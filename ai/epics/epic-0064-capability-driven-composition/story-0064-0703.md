## 1. Contexto

Adiciona ao `.claude/README.md` uma seção "Capabilities ativas neste projeto" gerada dinamicamente a partir do `ResolvedCapabilitySet` no momento da geração. Conteúdo:

- Lista das capabilities atomic ativas (sorted alphabetically).
- Profile usado.
- Versão do schema (3.0).
- Link para Rule 28 + ADR-0016.

Resultado: cada projeto downstream tem README documentando exatamente que capabilities estão ativas — útil para onboarding de novos devs.
