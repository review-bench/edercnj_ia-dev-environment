## 6. Decision Rationale

**Decisão:** Story executa pós-merge do PR principal — não during it.
**Motivo:** Status `Accepted` + "PR #N" + "Aceito em YYYY-MM-DD" só faz sentido após merge real. Executar antes geraria ADR com PR-number imaginário ou data prematura.
**Alternativa descartada:** Executar como parte do PR principal de Phase 7. Rejeitada porque PR # e merge date são post-merge facts.
**Consequência:** Esta story é "soft" — pode rodar via hook post-merge (automação) ou manualmente pelo release manager. Em ambos os casos, é um commit pequeno (Status flip + ~10 linhas de lições).
