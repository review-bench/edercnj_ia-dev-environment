## 6. Decision Rationale

**Decisão:** Preservar campo `Recommended Model:` via `--preserve-fields Recommended-Model` (similar ao Rule 22 fields).
**Motivo:** Rule 23 (Model Selection) é ortogonal a Rule 28 (Capability Frontmatter). Cada agent já tem model declarado — alterar em massa quebraria orçamento de tokens enforcement.
**Alternativa descartada:** Re-derivar `Recommended Model` no migration (e.g., `database-engineer` → Sonnet por default). Rejeitada porque (a) mistura escopos, (b) `Recommended Model` foi calibrado per-agent em EPIC-0050.
**Consequência:** Phase 2 não toca `Recommended Model`; modificações ficam para futura epic dedicada (Rule 23 evolution).
