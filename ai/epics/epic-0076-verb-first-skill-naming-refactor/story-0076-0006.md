# Story: 0076-0006 — Atualizar source of truth, Java, templates, docs e testes

## 1. Contexto

Depois que os clusters forem renomeados, o repositório inteiro precisa convergir para os nomes novos. Isso inclui Java que conhece nomes de skills, generated outputs, templates, rules, docs e testes.

Esta story é o ponto de convergência do épico. Qualquer rename não propagado aqui vira regressão silenciosa.

## 2. Acceptance Criteria

```gherkin
Cenario: Java conhece apenas nomes novos
  DADO classes e assemblers que referenciam skills por string
  QUANDO a story concluir
  ENTÃO essas referências apontam apenas para nomes novos

Cenario: docs e templates convergem
  DADO README, CLAUDE, rules e templates
  QUANDO a story concluir
  ENTÃO exemplos e links usam apenas nomes novos

Cenario: generated outputs são consistentes
  DADO a regeneração de .claude
  QUANDO o pipeline rodar
  ENTÃO o output reflete apenas o catálogo renomeado

Cenario: testes e goldens acompanham o rename
  DADO testes que assertam nomes e paths de skills
  QUANDO a story concluir
  ENTÃO eles passam a validar somente os nomes canônicos
```
