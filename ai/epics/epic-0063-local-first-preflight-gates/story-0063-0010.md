## 3. Contratos & Endpoints

### 3.1 Rule 24 §Camada 0 content (proposed)

```markdown
## §Camada 0 — Local Pre-Flight (EPIC-0063)

> **Related:** Rule 26 (Audit Gate Lifecycle — Hook layer), Rule 27 (Zero-Bypass).

### Definition

Camada 0 são gates que executam **localmente, na máquina do operator, ANTES** de qualquer
operação remota (`git push`, `gh pr create`). Diferentemente das Camadas 1-3 (normativa,
Stop hook, CI audit) que validam pós-fato, Camada 0 é **vinculante operacionalmente**:
um PreToolUse hook bloqueia o tool call antes de executar.

### Components

| Component | Path | Role |
| :--- | :--- | :--- |
| Pre-Flight Runner | `scripts/preflight.sh` | Executa em sequência: format, tests, coverage, content audits, telemetry check |
| PreToolUse Hook | `.claude/hooks/enforce-preflight-gates.sh` | Intercepta `git push`, `gh pr create`, `Skill x-pr-create` |
| Content Audit | `scripts/audit-review-content.sh` | Heurística sintática anti-stub |
| Envelope Audit | `scripts/audit-verify-envelope.sh` | Schema validation do verify-envelope.json |
| Coverage Local | `scripts/audit-coverage-local.sh` | Parsea jacoco e valida thresholds |
| Telemetry Audit | `scripts/audit-execution-integrity.sh --scope=telemetry` | Valida eventos NDJSON |

### Único Bypass

`CLAUDE_RECOVERY_MODE=1` é a ÚNICA variável de ambiente aceita pelo hook. Outras
(`CLAUDE_SKIP_AUDIT`, `CLAUDE_NO_ENFORCE`, etc) são IGNORADAS — hook prossegue
normalmente. `CLAUDE_RECOVERY_MODE=1` emite WARNING visível em stderr e registra
evento `recovery_mode_used` em NDJSON para audit log periódico (alerta se uso
> 5% das stories em janela 30d).

Cross-ref: Rule 27 RULE-059-07.

### Forbidden

- Bypass via `git commit -n` ou `--no-verify` (hook bloqueia incondicionalmente)
- Bypass via `gh pr merge --admin` (hook bloqueia)
- Adicionar nova variável de bypass sem amend desta rule + SemVer MINOR
```

## 8. Decision Rationale

**Decisão:** Camada **0** ao invés de Camada **5**.
**Motivo:** Numbering reflete ordem temporal, não ordem de importância. Camada 0 executa ANTES de tudo (pré-flight). Camada 5 sugere "última a executar".
**Alternativa descartada:** Camada 5 ou "Camada Pre". Rejeitado pelo argumento acima.
**Consequência:** Documentação enumera 0..4 (5 camadas total). Mitigação: documentação clara da semantica temporal.

**Decisão:** CLAUDE.md acrescenta parágrafo curto (não reescreve o block).
**Motivo:** Block existente já tem texto cuidadoso. Adicionar antes preserva contexto e adiciona Camada 0 como first thing.
**Alternativa descartada:** Reescrever todo o block. Rejeitado por risco de regression em texto existente.
**Consequência:** Block fica ligeiramente maior (+5 linhas). Aceito.
