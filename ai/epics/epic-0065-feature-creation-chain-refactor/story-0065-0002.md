- **Phases (com markers de telemetria — Rule 13 §Telemetry Markers):**
  - **P0 — Worktree:** invoca `x-git-worktree create --identifier feature-ideation-<slug> --branch docs/feature-<slug> --base develop` via `Skill(skill: "x-git-worktree", model: "haiku", args: "...")` (Pattern 1 INLINE-SKILL — Rule 13)

- **Sem invocação automática de `x-feature-create`** (RULE-005): operador revisa spec, depois invoca manualmente.

---

## 3. Entrega de Valor

**Medida:** Reduzir tempo "ter ideia" → "ter spec.md" de ~30 min para <5 min  
**Impacto:** Usuários podem iterar em especificação assistida  
**Risco mitigado:** Entrada manual de spec pré-requisito foi barreira de uso

---

## 4. Contrato de Dados

**Entrada:**
- Argumento: prosa livre inline (min 100 chars) **ou** path de arquivo `.txt`/`.md`
- Validação: <100 chars → exit 2 `OPERATIONAL_ERROR` (Rule 26) com mensagem "input prose too short — provide at least 100 characters"

**Saída:**
- Arquivo: `docs/specs/SPEC-<slug>-v1.md` (slug = kebab-case derivado das primeiras 5 palavras da prosa, ASCII-only, max 40 chars)
- Estrutura RA9 v2 minimal — 5 seções obrigatórias:
  1. `## Sistema` — domínio, papel, escopo de alto nível
  2. `## Escopo` — incluído/excluído/limites
  3. `## Regras` — RULE-001..N transversais
  4. `## Histórias` — lista preliminar (sem decompor)
  5. `## DoR / DoD` — gates iniciais
- Branch: `docs/feature-<slug>`
- PR: `docs/feature-<slug> → develop`, label `docs`, **sem auto-merge** (manual gate — D-R6 do epic; só `docs/<epic-id>-<slug>` PRs auto-merge)

**DoR (Definition of Ready):**
- [ ] story-0065-0001 mergeada (Rule 09 reconhece tipo `docs/`)
- [ ] `gh` CLI autenticado (`gh auth status` exit 0)
- [ ] `git remote get-url origin` aponta para repo válido com permissão de push
- [ ] Worktree base branch `develop` atualizado (`git fetch origin develop`)
