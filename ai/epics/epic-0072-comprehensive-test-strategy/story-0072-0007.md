## 1. Visão

Como **CI guardian**, quero CI script `audit-contract-breaking.sh` (Camada 2 — Rule 26) que:
1. Detecta breaking change em OpenAPI/proto/event-schema cruzando branch base vs PR (mesma classificação aplicada pela skill `x-test-contract`, story-0072-0004).
2. Verifica se PR documenta migração via entry "## Breaking" em `CHANGELOG.md` (formato compatível com `_TEMPLATE-CHANGELOG-ENTRY.md` que será entregue por EPIC-0071).
3. Bloqueia merge se breaking detectado E sem migration doc; passa com WARN se breaking detectado E migration doc presente.
4. Implementa `--self-check` (Rule 26).
5. Entry simultânea em `docs/audit-gates-catalog.md` (RULE-004 — Catalog-before-Add).

…porque skill `x-test-contract` roda em Phase 3 (story-0072-0008), mas Camada 2 (CI script independente) protege contra bypass — operador que ignora a skill via flag ainda é pego pelo audit.

## 2. Entrega de Valor

- **Valor primário:** Camada 2 sobre contracts; defesa em profundidade junto a Camada 3 (skill x-test-contract).
- **Valor secundário:** integração explícita com CHANGELOG cria contrato bidirecional — quem documenta a migração tem o gate; quem não documenta é bloqueado.
- **Métrica:** zero breaking changes em produção sem entry "## Breaking" no CHANGELOG do release que os introduziu (medido por audit log + CHANGELOG history).

## 3. Acceptance Criteria (Gherkin — 4 categorias mandatórias)

```gherkin
Cenario: Happy — sem breaking change
  DADO PR não modifica openapi.yaml/proto/avsc
  QUANDO audit-contract-breaking.sh roda
  ENTÃO exit 0 (OK) sem trabalho

Cenario: Degenerate — projeto sem contratos declarados
  DADO repositório sem openapi.yaml E sem **/*.proto E quality.contract.enabled=true
  QUANDO audit-contract-breaking.sh roda
  ENTÃO exit 0 (OK) com WARN "no contract artifacts found"

Cenario: Error — breaking sem migration doc bloqueia
  DADO PR muda openapi.yaml com breaking (campo removido)
  E sem entry "## Breaking" no CHANGELOG.md modificado pelo PR
  QUANDO audit-contract-breaking.sh roda
  ENTÃO exit 1 (CONTRACT_BREAKING_VIOLATION) com mensagem "breaking change detected; CHANGELOG.md needs '## Breaking' entry"
  E reporta diff completo dos artefatos de contrato

Cenario: Boundary — breaking documentado em CHANGELOG passa com WARN
  DADO PR muda proto3 com breaking (field removal)
  E PR adiciona entry "## Breaking" em CHANGELOG.md (regex match em "^##\\s+Breaking" no diff do CHANGELOG)
  QUANDO audit-contract-breaking.sh roda
  ENTÃO exit 0 (OK) com WARN "breaking change detected — documented migration accepted"
  E loga a justificativa para auditoria (path do log = TBD: `audits/` não existe na árvore atual; sugerir `governance/audits/contract-breaking-history.log` ou criar `audits/` — decidir em task-0072-0007-006 antes do impl)
```
