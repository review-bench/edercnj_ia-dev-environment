# História: Refator x-task-plan: C4 Code level obrigatório

**ID:** story-0077-0015
**Chave Jira:** —
**Status:** Pendente

## 1. Contexto & Escopo

Como **Arquiteto de Domínio**, eu quero refatorar x-task-plan para emitir C4 Code level (classes, packages, dependencies) como obrigatório, garantindo que implementação detalhada está sempre representada em C4 antes de coding.

x-task-plan gera tasks a partir de stories; refactor faz com que output inclua C4 Code diagrams: classes/packages de cada task, suas dependências, hexagonal layers (adapter/domain/application). Code level é o nível mais granular de C4, próximo ao código; é "obrigatório" na sense que x-task-plan output sem Code C4 é incompleto.

Valor: implementadores veem C4 Code antes de codificar; reduz surpresas de design, facilita peer review de arquitetura.

## 8. Decision Rationale

**Decisão:** C4 Code é obrigatório (não opcional); placeholder para TBD classes não permitido.

**Motivo:** Code level é "implementação", deve estar bem-definida antes de coding.

**Alternativa descartada:** C4 Code opcional (loses value), TBD allowed (vague design).

**Consequência:** x-task-plan requer mais tempo para gerar (mais detalhe); but value é alto.
