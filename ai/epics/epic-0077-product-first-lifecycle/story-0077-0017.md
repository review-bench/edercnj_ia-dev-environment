# História: Integração C4 validador em phase-gate post + golden fixtures

**ID:** story-0077-0017
**Chave Jira:** —
**Status:** Pendente

## 1. Contexto & Escopo

Como **Líder de Qualidade**, eu quero integrar x-internal-c4-validate em fase-gate post-implementation (EPIC-0069 extension), garantindo que toda story/epic passa C4 validation antes de merge, prevenindo arquitetura degradation.

Phase-gate é mecanismo de verificação que roda post-implementation; EPIC-0069 define gates (coverage ≥ 95%, etc.); EPIC-0077 adiciona C4 gate: "C4 Context+Container+Component+Code presentes e válidos, inward-only dependencies respeitadas". Integração envolve: hook em x-status-reconcile que roda validação, rejeita status "Done" se C4 invalid, relatório que mostra quais rules falharam.

Valor: C4 quality gate previne merge de código com arquitetura inválida; arquitetura EPIC-0077 é protegida post-hoc.

## 5. Quality Gates

### 5.2 Acceptance Criteria (Gherkin)

```gherkin
Cenário: Phase-gate bloqueado se C4 Context missing
  DADO que story foi implementada sem C4 Context diagram
  QUANDO x-status-reconcile --finalize-story executa
  ENTÃO phase-gate rejeita com erro "C4 Context mandatory missing"
  E status permanece "Em Andamento", não muda para "Concluída"

Cenário: Phase-gate passa se C4 valid + inward-only
  DADO que story tem C4 Context+Container+Component+Code
  E todas dependencies são inward-only
  QUANDO x-status-reconcile --finalize-story executa
  ENTÃO phase-gate passa
  E status muda para "Concluída"

Cenário: Relatório C4 mostra violations e remediação
  DADO que phase-gate falhou
  QUANDO relatório é gerado
  ENTÃO violations são listadas (ex: "application→adapter dependency")
  E sugestão de fix é incluída
```

### 5.3 Definition of Done (DoD Local)

- [ ] Bloqueia merge se C4 invalid

## 8. Decision Rationale

**Decisão:** Phase-gate C4 é blocker (não warning); nenhuma story incompleta C4 é merged.

**Motivo:** C4 é governance essencial; warnings são ignoradas.

**Alternativa descartada:** C4 como warning (violations ignoradas).

**Consequência:** Pode desacelerar merge de stories incompletas C4; valor é alto (arquitetura protegida).
