## 1. Contexto & Escopo

Como **Engenheiro de Automação**, eu quero implementar skill x-create-product, que transforma ideações em Produtos com RNFs Root e primeiro Capability (C1) stub, garantindo que Product-First Lifecycle tenha entrada de CLI automática.

x-create-product é a primeira skill de EPIC-0077: lê arquivo ideação (_TEMPLATE-IDEATION.md), validaforma, gera numeração produto (product-NNNN), cria artifact produto (_PRODUCT.md com 8 seções + RNFs Root), e stub de C1 (primeira capability). Execução é idempotent (rerun gera mesmo product-id).

Valor: automação completa ideação → produto, eliminando manual artifact creation e reduza tempo de transformação ideação para 5 minutos.

## 8. Decision Rationale

**Decisão:** Skill gera C1 stub automaticamente a partir de ideação; não requer input separado de capability.

**Motivo:** Cada produto precisa de ≥ 1 capability; C1 stub fornece ponto de partida para refinamento manual. Reduz passos manual downstream.

**Alternativa descartada:** Requerer input separado de capability (overhead), não gerar C1 (incomplete product state).

**Consequência:** C1 stub é template copy com linkage a produto; refinamento necessário por PM/architect.
