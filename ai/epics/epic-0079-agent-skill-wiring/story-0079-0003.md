# História: Migrar 8 skills de review especializado para agent dispatch

**ID:** story-0079-0003  
**Chave Jira:** N/A  
**Status:** Pendente

---

## 1. Visão

Como **mantainer das review skills especializadas**, quero migrar `x-review-qa`, `x-review-performance`, `x-review-database`, `x-review-devops`, `x-review-security`, `x-review-api`, `x-review-observability` e `x-review-events` para que cada uma despache seu agente específico via `subagent_type: "<agent-name>"` em vez de duplicar a persona inline em `general-purpose`, para que revisões especializadas rotem no modelo correto (Sonnet em vez de Opus herdado) e a persona de cada especialista seja mantida em um único arquivo canônico.

---

## 2. Persona & Cenário

**Persona:** Review Skill Maintainer gerenciando 8 skills de especialistas de review  
**Cenário de uso:** x-review-codebase despacha 8 review skills em paralelo. Cada skill atualmente duplica o corpo de persona do especialista (30-40 linhas de `You are a Senior Security Engineer...`). Após o merge, cada skill apenas referencia `subagent_type: "security-engineer"` e o prompt contém apenas o contexto do code review a ser feito.  
**Dor atual:** 8 skills com ~30-40 linhas de persona duplicada cada = ~280 linhas de duplicação que devem ser mantidas em sincronia  
**Critério de sucesso pessoal:** "Cada review skill tem ≤5 linhas de Agent() call sem nenhuma linha de persona inline"  
**Contexto técnico relevante:** O `x-review-codebase` chama essas 8 skills via `Skill(skill: "x-review-*")` — a migração não afeta os callers, apenas a implementação interna de cada review skill.

---

## 3. Entrega de Valor

- **Valor Principal:** ~280 linhas de persona duplicada eliminadas; tier Sonnet garantido para todos os reviewers (economizando ~2x custo vs Opus herdado)
- **Métrica de Sucesso:** `grep -rn 'You are a Senior' src/.../skills/review/x-review-*/SKILL.md` retorna 0 ocorrências
- **Impacto no Negócio:** Redução de custo de token em reviews (Sonnet vs Opus); manutenção de persona de especialista O(1) por papel

## 8. Decision Rationale

**Decisão:** Migrar todas as 8 review skills em uma única story, em dois batches de tasks paralelas  
**Motivo:** As 8 skills têm o mesmo padrão de migração; consolidar em uma story reduz overhead de PR e revisão; os dois batches permitem paralelismo de execução  
**Alternativa descartada:** Uma story por review skill (8 stories) — overhead de PR excessivo para mudanças estruturalmente idênticas  
**Consequência:** Um PR maior, mas com padrão repetitivo e fácil de revisar; risco de regressão reduzido pela estrutura homogênea
