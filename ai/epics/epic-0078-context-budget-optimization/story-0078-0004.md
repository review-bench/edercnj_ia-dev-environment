## 1. Contexto & Escopo

Como **LLM context budget owner (CLAUDE.md producer for ClaudeMdAssembler)**, eu quero extrair os ~14 blocos `> Concluded — EPIC-XXXX` do CLAUDE.md raiz para `docs/epics-history.md`, garantindo redução de ~3-4k tokens always-loaded sem perder rastreabilidade histórica.

CLAUDE.md raiz hoje carrega ~5.5k tokens dos quais ~70% são blocos históricos descrevendo epics já concluídos (EPIC-0041 paralelismo, EPIC-0045 CI-watch, EPIC-0055 task hierarchy, etc.). Esses blocos são úteis como referência de "como chegamos aqui" mas não como contrato ativo — pertencem semanticamente a `docs/epics-history.md` (lazy-loadable). CLAUDE.md raiz deve manter apenas: (a) executive summary do projeto; (b) link para `docs/epics-history.md`; (c) blocos "In progress" (epics em voo); (d) blocos críticos always-active (ZERO-BYPASS, EXECUTION INTEGRITY, REFINEMENT GATE).

Alvo: CLAUDE.md ≤200 linhas (atual ~340 linhas). `ClaudeMdAssembler` edita o **source-of-truth template** em `src/main/resources/targets/claude/CLAUDE.md.template` (ou `CLAUDE.md` se template plano), e a saída materializada (`.claude/CLAUDE.md` por perfil) é regenerada via golden test. Não há geração condicional dinâmica — extração é one-shot edit no template seguido por regeneração de goldens nos 11 perfis canônicos.

### 3.3 Concluded Block Detection — Regex Contract

`ClaudeMdAssembler` (ou script de extração) usa o seguinte regex (multiline-aware, ECMAScript-compatible) para localizar blocos a mover:

```regex
^>?\s*\*\*Concluded\s+—\s+(EPIC-\d{4})\b.*?\.\*\*$
```

| Componente | Significado |
| :--- | :--- |
| `^>?` | Linha pode iniciar com `> ` (blockquote markdown) ou sem |
| `\*\*Concluded\s+—\s+` | Literal `**Concluded — ` (com em-dash U+2014) |
| `(EPIC-\d{4})` | Captura grupo 1: identificador `EPIC-NNNN` |
| `\b.*?\.\*\*$` | Resto do header até `.**` final (non-greedy) |

Bloco completo = header line (match acima) + linhas subsequentes até a próxima linha em branco seguida por header diferente (heurística: bloco termina quando próximo `>` seguido de `**` ou início de seção `##`).

**Não-match (preservar em CLAUDE.md):** linhas começando com `> **In progress —`, `> **ZERO-BYPASS`, `> **EXECUTION INTEGRITY`, `> **REFINEMENT GATE`.

## 8. Decision Rationale

**Decisão:** Mover blocos "Concluded" para `docs/epics-history.md`; manter blocos "In progress" em CLAUDE.md.
**Motivo:** Blocos "In progress" são contrato ativo (epics em voo afetam decisões correntes); blocos "Concluded" são histórico arquivado.
**Alternativa descartada:** Mover tudo (incluindo "In progress") para `docs/`. Rejeitado: operadores precisam de visibilidade imediata de epics ativos sem fazer `Read docs/epics-history.md`.
**Consequência:** Quando um epic conclui, regra editorial: mover seu bloco de "In progress" → `docs/epics-history.md` (não fica em CLAUDE.md). Documentar em `_TEMPLATE-RULE.md` ou checklist de release.
