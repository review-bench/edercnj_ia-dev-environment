## 8. Decision Rationale

**Decisão:** 6 cenários (5 funcionais + 1 dogfood); fixtures isoladas para paralelismo.
**Motivo:** dogfood comprova "circuito fechado" — sistema gera memória do próprio épico que o criou. Sinal mais forte de funcionamento.
**Alternativa descartada:** apenas 5 cenários sem dogfood. Rejeitado: perde meta-prova.
**Consequência:** cenário 6 produz arquivo real em `ai/memory/` — está no PR final, mergea junto. Aceitável.

**Decisão:** CHANGELOG MINOR (additive, no breaking).
**Motivo:** EPIC-0075 só adiciona capability + skills + rule + audit; não quebra contratos existentes.
**Alternativa descartada:** MAJOR. Rejeitado: nenhuma quebra (Rule 27 surface é aditiva).

**Decisão:** sem mudança em `x-release` (EPIC-0067).
**Motivo:** fluxo de release existente já contempla CHANGELOG + tag; apenas precisa do entry pronto. EPIC-0075 não muda contratos de release.
**Alternativa descartada:** integrar geração de summary em `x-release`. Rejeitado: summary é evidência de conclusão de épico, não de release; pertence a `x-epic-implement` (story 0005).

**Decisão:** dogfood é teste real (não mockado) que produz arquivo no PR.
**Motivo:** prova de fogo. Mock perderia o ponto.
**Alternativa descartada:** mockear. Rejeitado: zero valor de evidência.
