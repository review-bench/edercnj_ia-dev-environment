# Rule 28 — Capability Frontmatter Contract

> **Related:** Rule 13 (Skill Invocation Protocol), Rule 22 (Skill Visibility), Rule 26 (Audit Gate Lifecycle).
> **Introduced by:** EPIC-0064 (Capability-Driven Composition Refactor).
> **ADR:** ADR-0016 — Capability-Driven Composition.
> **Full reference (capability ID format, glob rules, 4 YAML examples, fragment slot contract, migration notes):**
> `Read src/main/resources/targets/claude/knowledge/governance/capability-composition.md`

## Scope

Applies to all 6 artifact types generated by `ia-dev-env`: Skill, Rule, Knowledge Pack, Agent, Hook, Template.
Internal skills (`x-internal-*`) follow the same contract — no exception.

## Invariantes (8)

1. **Declaração obrigatória.** Every artifact outside `_common/` MUST declare `requires-capabilities: [...]` in frontmatter v3.0. Absence is a build error (`audit-capability-coverage.sh` exit 1).
2. **Schema v3.0 estrito.** Frontmatter validated by `governance/schemas/frontmatter-3.0.json`. v2 (no `requires-capabilities`) breaks build.
3. **Capability ID válido.** IDs in `requires-capabilities`, `requires-any`, `excludes-capabilities` must exist in `capabilities/<category>/<id>.yaml`. Unknown ID → `audit-capability-graph.sh` exit 3 (`UnknownCapability`).
4. **Excludes simétrico.** If A declares `excludes-capabilities: [B]`, then B MUST declare `excludes-capabilities: [A]`. Asymmetry → exit 2 (`AsymmetricMutex`).
5. **Composition-priority bounded.** If declared, `composition-priority ∈ [0, 100]`. Default 50.
6. **Fragment ≠ artifact standalone.** Files under `fragments/` MUST declare `fragment-slot: {slot, fragment-id, fragment-order}`. Fragments never generate their own output.
7. **Slot ↔ Fragment coerência.** Every `fragment-slots: [{slot: X}]` on parent must have at least one `{{ slot: X }}` or `{{ #each fragments.X }}` in the parent body.
8. **Sem retrocompatibilidade.** Schema v3.0 is mandatory from EPIC-0064 merge. No dual-mode v2/v3.

## Forbidden

- Frontmatter without `requires-capabilities` outside `_common/`.
- Capability ID without `category.subcategory.atomic` format.
- Glob without category prefix (`*.database.postgres` is invalid).
- `fragment-slot` outside a `fragments/` directory.
- `excludes-capabilities` referencing a non-existent capability ID.
- Schema v2 (no `requires-capabilities`) — breaks build.

## Permitted

- `requires-capabilities: []` (universal — always included).
- `requires-any: [a, b]` syntax for OR predicates.
- Multiple `fragment-slots` on the same parent artifact.
- Unknown extra fields (additionalProperties=true) — tolerated for extensibility.
